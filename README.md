**วัตถุประสงค์**

-เพื่อลดไม่ยุ่งยาก
-เพื่อทำให้วางแผนได้ดีและใช้ได้จริง

**กลุ่มลูกค้า**
-วัยรุ่น -ผู้ใหญ่

**ฟังชั่น**
-วางแผนเที่ยว
-คำนวณรายจ่าย

**เป้าหมายของระบบ**

-ประมวลผลข้อมูลตามกฎหรือวัตถุประสงค์ของระบบ
-แสดงผลลัพธ์ที่ผู้ใช้ต้องการ
